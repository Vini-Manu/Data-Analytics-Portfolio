# Vinitha Manoj — Data Analytics Portfolio

Three end-to-end BI projects built during a Data Science & Analytics internship at
**BLUEKWET**, each using a different tool on a different real-world dataset — showing
range across Excel, Power BI, and Tableau.

| Project | Tool | Dataset | Highlight |
|---|---|---|---|
| [Perfume Retail Sales Dashboard](./EXCEL%20PROJECT) | Excel | 392,800 transactions, 5 UAE branches | AED 108.6M revenue analyzed, pivot-table driven |
| [Restaurant Performance Dashboard](./POWERBI) | Power BI | 3,600 orders, 3 Dubai branches | Star-schema model, 13 DAX measures |
| [Student Enrollment & Revenue Analysis](./TABLEAU) | Tableau | 2,000 enrollments, 6 UAE branches | AED 13.9M in fees tracked, 65.7% collection rate |

Each folder contains the original working file (Excel/`.pbix`/`.twbx`), a project
presentation, and a dashboard screenshot.
